# Oar Load Calculator

A single-page rowing rigging tool. Enter the squad, the crew's average weight (lb or kg) and the boat class. It shows:

- the baseline spread, inboard, outboard, oar length, load and gearing from the USRowing Level 2 Coaches Manual rigging table (Module 5, Figure 7, club level)
- a ladder of lighter and heavier loads with the settings to reach each one, either by changing oar length or by moving the collar with clams

## Formulas (Module 5, Ch. 2)

- Load (sweep) = outboard ÷ spread
- Load (sculling) = outboard ÷ (span ÷ 2)
- Gearing = outboard ÷ inboard
- Outboard = oar length − inboard

Crew average weight selects the lightweight or open table using World Rowing crew-average limits (men 70 kg, women 57 kg). The manual does not scale load by body weight within a table.

## Use

Open `index.html` in any browser, or visit the GitHub Pages site. No build step; everything is in one file.
